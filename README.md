# 🏡 Pousada Secreta

Projeto desenvolvido durante meus estudos de **Desenvolvimento Web**, com o objetivo de praticar a criação de uma página para uma pousada, aplicando conceitos de **HTML5 e CSS3**.

O projeto simula o site de uma pousada, apresentando informações sobre hospedagem, quartos, comodidades e opções disponíveis para os hóspedes, com uma interface simples, organizada e agradável.

---

## 📌 Sobre o projeto

A **Pousada Secreta** foi desenvolvida como um projeto de aprendizado para colocar em prática os conhecimentos adquiridos durante meus estudos de desenvolvimento web.

A proposta foi criar uma página visualmente agradável para uma pousada, trabalhando principalmente a estruturação do conteúdo, organização dos elementos e estilização da interface.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

---

## 💻 Funcionalidades

- Página inicial com apresentação da pousada
- Seção de informações sobre a hospedagem
- Apresentação dos quartos disponíveis
- Seção de comodidades
- Lista de informações e serviços oferecidos
- Navegação entre as seções da página

---

## 📚 O que aprendi

Durante o desenvolvimento deste projeto, pude praticar:

- Estruturação de páginas utilizando **HTML semântico**
- Organização de conteúdo utilizando diferentes elementos HTML
- Estilização de páginas utilizando **CSS**
- Utilização de **Flexbox**
- Criação e estilização de listas e cards
- Trabalho com imagens e elementos visuais
- Utilização de variáveis CSS com `:root`
- Organização de arquivos e pastas de um projeto web
